# job-market-analysis
Exploratory analysis of 742 job postings (salary, location, industry, skills) with Python and an interactive Power BI dashboard.

## Overview
Exploratory analysis of job-posting data to understand hiring trends, salary
patterns, industry demand, and the skills employers ask for.

## Dataset
- Marketing.csv: 742 job postings, 42 features
- Salary values are in USD thousands
- Skill columns use 1 when a skill is required and 0 otherwise

## Data Preparation
- Treated -1 as missing values
- Removed duplicate records
- Created a state field from the location column

## Analysis
- Job postings by state
- Salary comparison by state and job title
- Top industries, companies, and job titles
- In-demand skills
- Salary by degree category and by company rating
